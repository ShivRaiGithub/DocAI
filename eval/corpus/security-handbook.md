# Employee Security Handbook

Passwords must be at least 14 characters long. Passwords are not expired on a schedule, only when a compromise is suspected.

Multi-factor authentication (MFA) is mandatory for every company account, including email and the code repository.

If a laptop or phone is lost or stolen, report it to security@acme.example within 1 hour so the device can be locked remotely.

Use the company VPN whenever you connect from public wifi, such as in cafes or airports.
